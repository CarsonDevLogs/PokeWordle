# PokeWordle 
A Pokémon‑themed twist on the classic Wordle formula

PokeWordle is a simple, browser‑based guessing game where players try to identify a mystery Pokémon within a limited number of guesses. Inspired by Wordle and built entirely in HTML, this project is a fun way to blend Pokémon knowledge with quick daily puzzle gameplay. 

✨ Features:
Clean, lightweight HTML implementation
Pokémon‑themed UI and logic
Quick, replayable gameplay loop
